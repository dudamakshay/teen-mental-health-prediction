Project Overview

Problem Statement

Teen mental health issues are increasing because of stress, sleep deprivation, anxiety, and excessive social media usage.

Project Goal

Analyze behavioral patterns and build a machine learning model to predict depression risk among teenagers.

Machine Learning

Built a Random Forest machine learning model using Scikit-learn to predict mental health risk.

Effects of Teen Depression

😴 Sleep Problems

Teens with depression often showed lower sleep duration and irregular sleeping habits.

📉 Academic Impact

Higher stress and anxiety levels affected concentration, productivity, and academic performance.

📱 Social Media Addiction

Excessive social media usage was associated with higher depression probability among teenagers.

🧠 Mental Stress

Stress and anxiety were major behavioral factors affecting mental health.

Popular Social Media Platforms

Instagram

Heavy Instagram usage may increase comparison anxiety, screen addiction, and emotional stress among teenagers.

TikTok

Excessive short-video consumption may affect sleep, focus, and mental well-being.

WhatsApp

Constant messaging and online activity may increase stress and reduce offline social interaction.

Resume Project Description

  • Performed data cleaning and exploratory data analysis using Python and Pandas.
  • Created visualizations using Seaborn and Matplotlib to analyze stress, anxiety, sleep, and social media usage.
  • Built a Random Forest machine learning model to predict teen depression risk.
  • Used feature importance analysis to identify major behavioral factors affecting mental health.
  • Developed an HTML portfolio and PowerPoint presentation for project showcasing.
